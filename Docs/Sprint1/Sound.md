## 2. 알려진 이슈 — 동시 피격과 오디오 쿨다운 (Docs/Tasks.md)

**기록된 사실 (Tasks.md 2026-11-11):** 같은 시점의 코어 피격 2회 → HP 100→86(−14), `CueRequested` 2회 발생, 그러나 `CoreDamaged`의 `LastPlayed`는 두 번째 요청에서 갱신되지 않음 → 실제 재생 1회. HUD는 0.35초 창에서 `×2 · -14`로 합산하도록 수정됨. 사운드 규칙은 변경되지 않았고, 격리 청취와 디렉터 검토 사운드 악센트가 대기 중.

**원인:** `TryPlay`의 이벤트별 0.35초 쿨다운(Audio:52-55). 적마다 0.8초 공격 타이머가 따로 돌기 때문에 내부 적이 많을수록 0.35초 안에 여러 명중이 겹치고, 같은 이벤트는 0.35초당 최대 1회만 들림. 플레이어+코어 혼합 피격은 이벤트가 달라 둘 다 재생됨.

**영향:** 귀로는 "한 대 맞음", 화면은 "×2 −14" → 소리와 HUD가 다른 피해량을 전달. 50 경고 근처처럼 적이 많을 때 차이가 커짐.

**선택지 (디렉터 결정 필요, 어떤 것도 구현하지 않음):**

| 안 | 내용 | 장점 | 단점 |
| --- | --- | --- | --- |
| S-A 현행 유지 | 0.35초당 1회, HUD가 합산 담당 | 소음·클리핑 없음, 변경 없음 | 소리와 HUD 불일치 지속 |
| **S-B 합산 악센트 (권장)** | HUD와 같은 0.35초 창에서 첫 명중은 즉시 재생, 창 안의 추가 명중 수에 따라 창 종료 시 또는 즉시 "다중 피격" 악센트(짧은 저음 레이어 1회, 피격 수 2 / 3+ 두 단계) | HUD `×N`과 1:1 대응, 재생 수 상한 유지 | `LastStopAudio`에 창 상태·악센트 클립 추가 필요 |
| S-C 쿨다운 단축 + 보이스 상한 | 피격 큐 쿨다운 0.35→0.06, 동시 재생 최대 3, 2번째부터 −3dB·피치 변주 | 명중마다 소리 | 다수 적에서 소음, 덕킹과 상호작용 복잡 |

권장: **S-B**. HUD 피드백 창(Proto:1471-1487)과 같은 시간 기준을 써서 "보이는 것 = 들리는 것"을 유지. 피해 규칙·명중 간격은 그대로.

S-B 수락 기준:
1. 같은 프레임 코어 피격 2회 → 기본 피격음 1회 + 악센트(2단계) 1회, HUD `×2`.
2. 0.35초 안 3회 이상 → 악센트(3+단계) 1회, 악센트는 창당 최대 1회.
3. 0.35초 간격을 넘는 단일 피격 → 기본 피격음만, 악센트 없음.
4. 플레이어·코어 혼합 → 각자 기본음 1회씩, 악센트는 총 피격 수 기준 1회.
5. HP 0이 되는 명중 → 피격음 후 GameOver 큐, 악센트 생략.
6. `CueRequested` 카운트가 실제 명중 수와 일치(기존 계약 유지).

## 4. 믹스 / 볼륨 계획

### 4-1. 버스 구조 (Audio Mixer 도입 제안, Development 팀 승인 필요)

```
Master (0 dB, 리미터 −1 dBFS)
├─ Alerts      : GameOver, Arrival, BreachWarningOn/Off/Loop, LowHealth   (덕킹 안 받음)
├─ Damage      : PlayerDamaged, CoreDamaged, HitMultiAccent               (덕킹 안 받음)
├─ UI          : ViewChanged, LevelUpOpen/Choose, HintToast, Restart
├─ Combat      : 경로 B 전체(발사·명중·처치·스윙·화염)                    (Damage 발생 시 덕킹)
└─ Music/Amb   : BGM, EngineLoop                                          (Alerts·Damage 시 덕킹)
```

현재 코드에는 Mixer가 없으며 경로 B의 AudioSource 볼륨을 직접 낮추는 방식(Proto:171-173). 이 방식은 이미 재생 중인 원샷까지 같이 줄어드는 특성이 있음 — 의도와 맞는지 청취 확인 필요.

### 4-3. 우선순위 / 동시 재생 규칙 (제안)

1. GameOver·Arrival 재생 시 Combat·Music 즉시 −12dB, 이후 큐 차단(결과 화면).
2. Damage 발생 시 Combat −12dB / 0.30초(현행 0.25배 ≈ −12dB와 동일 유지).
3. 연사 큐 동시 보이스 상한: BusCannonFire 2, EnemyHit 3, EnemyKill 3.
4. 레벨업 중(timeScale 0): Combat 큐는 원래 발생하지 않음(DamageEnemy 차단, Proto:1233). Music/Amb는 로우패스로 "일시정지 느낌".
5. 시점별 필터: 내부 시점에서 외부 Combat 큐에 로우패스(약 1.5kHz) — "밖도 진행 중"을 소리로 전달.

### 4-4. 에셋 사양 / 라이선스 체크리스트 (실제 파일 제작 시)

- 포맷: WAV 44.1kHz/16bit 원본, Unity Import는 짧은 SFX `Decompress On Load`, BGM/루프는 `Streaming` + Vorbis.
- 루프: 제로 크로싱 루프 포인트, 클릭 없음 확인.
- 이름: `SFX_<Group>_<EventName>_v1.wav` (예: `SFX_Damage_CoreDamaged_v1.wav`), 폴더 `Assets/Audio/<Group>/`.
- 라이선스: 출처·라이선스(CC0/구매/자체 제작)·저작자를 `Assets/Audio/LICENSES.md`(생성 시)에 기록. AI 생성 시 사용 도구·약관 기록.
- `.meta` GUID 보존, 기존 합성 큐는 클립 미할당 시 폴백으로 유지.
