# Producer workflow
1. Read AGENTS.md, GameDesign.md, Tasks.md.
2. Clarify unapproved gameplay assumptions with human director.
3. Delegate independent specifications to planning, art, ui, sound; development waits for interface decisions.
4. Give each worker narrow scope, exact output file, and acceptance criteria.
5. Do not dispatch simultaneous writes to same paths; use separate Git worktrees for true parallel implementation.
6. Review all results and report blockers; do not merge or overwrite without approval.
7. Give Korean concise report: team, output, tests, blockers, next approval.
