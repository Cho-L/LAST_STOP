# 제출 검증 기록 — 2026-11-19

Unity 6000.3.15f1, Windows 64비트 제출 후보입니다.

## 이번 보완

- 차내 화염기는 내부 조작 중 게임 시간으로 쿨다운을 누적하고, 준비된 뒤 다음 Space 공격에서 발동합니다.
- 레벨업 제안은 한 프레임 전투가 끝난 뒤 처리합니다. 같은 프레임의 HP 0 패배와 480초 도착은 기존 업데이트 순서대로 먼저 처리합니다.
- 일시정지 상태의 근접 투사체와 결과·레벨업 중 적 피해를 차단합니다.
- 강화 카드 문구를 실제 효과와 맞췄습니다.
- 이전 개발 변경인 방향별 발사 섬광, 결과 화면 잘림 수정, R 재시작 초기화도 포함합니다.

## 실제 수행한 검증

- Unity Play Mode의 임시 C# 프로브로 25개 조건을 검사했습니다. [결과](Verification/SubmissionRegressionResults.txt)
- 30/60/120 FPS 고정 게임 시간으로 화염기를 측정했습니다. 발동 간격은 0.733~0.800초였습니다. 0.7초 준비 후 다음 공격에서 발동하므로 공격 간격의 오차가 포함됩니다.
- 정지 중 겹친 투사체, 레벨업·결과 중 피해 차단, 접촉 1:1 이동과 적 체력·공유 HP 보존, 50마리 경고, 실제 피격에 따른 HP 0 패배를 확인했습니다.
- 임시 가상 키보드로 처음부터 플레이해 레벨업 선택, 내부 전환·공격 대응, 480초 도착과 R 재시작을 검사했습니다. 도착은 202처치, 생존력 100입니다.
- 다음 런은 내부에 개입하지 않고 차체 보강을 골랐고, 코어 실제 피격으로 25.73초에 HP 0 패배를 확인했습니다. R로 생존력 100·레벨 1·외부 화면과 게임 인스턴스 한 개를 확인했습니다. [결과](Verification/SubmissionRouteResults.txt)
- 자동 플레이는 고정 30 FPS 게임 시간을 사용해 가속했습니다. 정상 속도의 사람이 조작한 완주와 조작감 평가는 후속 확인 항목입니다.

## Windows 배포 빌드

- HEAD의 깨끗한 파일과 제출할 스크립트 두 개로 격리 프로젝트를 구성해 StandaloneWindows64 빌드를 실행했습니다. Unity CLI와 Build Report 모두 성공했고 Unity 종료 코드는 0입니다.
- 검증한 원본 스크립트와 빌드 복사본의 SHA-256이 일치합니다.
- 실제 실행 파일을 창 모드로 열어 한글 HUD와 게임 시간 진행을 확인했습니다. 초기 실행 로그에서 NullReferenceException, MissingReferenceException, 로딩 실패와 컴파일 오류는 없었습니다.
- Windows 포커스 자동화 제약으로 실제 Player의 키 입력 회귀는 완료하지 못했습니다. 위 입력·재시작 결과는 Unity Play Mode 검증입니다.
- 배포 ZIP에는 실행 안내와 글꼴 라이선스를 포함합니다. Burst 디버그 정보 폴더는 배포에서 제외합니다.

## 검증의 한계

이 결과는 실행한 Play Mode 프로브 기록입니다. 프로젝트 NUnit EditMode/PlayMode 테스트 스위트는 아직 없습니다. 성능 예산 측정, 게임 오디오 단독 청취, 게임패드·키 재지정, 전체 해상도 범위는 미검증입니다.
