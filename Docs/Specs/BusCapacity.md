# 버스 수용량과 버스 감속 (명세 초안)

상태: 방향은 감독 결정(2026-11-27). 표시된 수치는 모두 **제안 — 감독 검토 필요**.

## 1. 결정된 방향
- 버스 내부에는 **수용량**이 있다. 감독 선택: 경고(50)보다 여유 있게, 예시 값 60.
- 수용량이 남아 있으면 지금처럼 버스에 닿은 외부 적이 1:1로 내부에 들어온다.
- 수용량이 가득 차면, 버스에 닿은 외부 적은 들어오지 못하고 **버스에 매달린다**.
- 매달린 적 수에 비례해 **버스가 점점 느려지고**, 일정 수 이상이면 멈춘다. 떼어낼수록 다시 빨라진다.
- 도착은 8분 타이머가 아니라 **이동 거리 진행도**로 계산한다. 최고 속도로 달리면 8분(480초)에 도착한다.

## 2. 바뀌지 않는 규칙
- 공유 HP는 실제 적의 타격으로만 줄어든다. 매달린 적과 버스 감속은 HP를 깎지 않는다.
- 봉쇄 메커닉은 없다. 수용량은 "문을 닫는" 장치가 아니라 버스 안이 물리적으로 가득 찬 상태다.
- 내부 50마리는 여전히 경고 기준이며, 그것만으로 게임 오버가 아니다.
- HP 0이면 패배, 도착하면 승리, R로 재시작.
- 레벨업 중에는 모든 것이 멈춘다(진행도 포함).

## 3. 제안 수치와 규칙 [감독 검토 필요]
| 항목 | 제안 | 비고 |
|---|---|---|
| 수용량 | 60 | 50 경고 이후 10마리 여유 |
| 감속 공식 | 속도 = 최고 속도 x max(0, 1 − 0.08 x 매달린 수) | 13마리 이상이면 정지 |
| 매달린 적의 위치 | 버스 외곽의 정해진 슬롯(최대 16개)에 붙음 | 슬롯이 다 차면 그 뒤 적은 버스 주변에서 대기 |
| 매달린 적 처리 | 버스 무기가 매달린 적도 공격 대상으로 삼는다 | 내부로 들어간 적은 지금처럼 추적하지 않는다 |
| 빈자리 생김 | 내부 적이 죽어 수용량에 여유가 생기면, 가장 먼저 매달린 적부터 1:1로 들어온다 | 진입 경직 규칙 동일 적용 |
| 도착 거리 | 최고 속도 x 480초 | HUD에 남은 거리(또는 %) 표시 |

## 4. 위험과 주의
- **악순환 위험:** 지금 적 스폰은 경과 시간 기준이다. 버스가 느려지면 도착이 늦어지고, 그동안 더 많은 적이 나와 더 느려질 수 있다. 스폰을 시간 기준으로 둘지, 진행도 기준으로 바꿀지 결정 필요.
- **코드 영향:** 도착 판정(`DemoDurationSeconds = 480f`, `Assets/Scripts/LastStopPrototype.cs:44`)과 종료 처리(`EndArrival`, `:1518`)를 진행도 기반으로 바꿔야 한다. 도로 스크롤(`LastStopRoadMotion`)은 지금은 연출뿐이라 버스 속도와 연결해야 한다. 외부 적의 1:1 이전(`TransferEnemyInside`, `:767`)에 수용량 검사가 들어간다.
- **테스트:** 수용량 미만에서 1:1 진입 유지, 수용량 도달 시 진입 중단과 매달림, 매달린 수별 속도, 정지 상태에서 진행도 정지, 빈자리 생기면 1:1 진입 재개, 매달림·감속만으로 HP 불변, 레벨업 중 진행도 정지.
